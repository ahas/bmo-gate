# System reference index

- This is the index of the system's own reference documents that the system-documents gate may attach to a chat turn, in every chat.
- A slug here names the system document of the same name the deployment ships; a slug not listed here never resolves.
- Each entry below stands as a fragment row, which is what the gate is offered and what its answer resolves against (the brain's `docs/fragments.md`).
- An entry says what kind of document it is and the questions or situations a turn needs it for, never a list of the words it mentions: the words every turn carries would attach it to every turn (the brain's `docs/fragments.md`, 「The shape a title must have」).

## The system

- structure — the document of the system's large structure: what the chat providers, the chat receiver, the chat agent, the gates, the workers and the co-workers each are and how they divide the work, when the chat agent wakes, and the principle by which a request becomes an item or is done directly. Attached only when a turn asks about the structure of the whole system or discusses its design or a change to it; the word turning up in an ordinary work order or progress report is not enough.
- wording — the room language's word choice and spelling, loan words among them: the common word, a native word or not, and which banned terms are replaced by what. Needed only when a reply is about which word to use or how to spell it, or the owner corrects a word; an ordinary reply does not need it.
